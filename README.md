# Interactive 3D Website

### A 3D web portfolio showcasing the integration of an interactive 3D scene into the web ecosystem using **Vue 3** and **TresJS**.

## 🌐 [Live Demo](https://omar-hasan-3d.web.app)

---

## 🛠️ Tech Stack

- **Framework:** Vue 3 (Composition API) + Vite
- **3D Engine:** Three.js & TresJS (`@tresjs/core`)
- **Hosting:** Firebase Hosting


---

## 🚀 Project Setup

```sh
npm install
```

- ### Compile and Hot-Reload for Development

```sh
npm run dev
```

- ### Compile and Minify for Production

```sh
npm run build
```

---

## 🐳 Run with Docker

### 1️⃣ Build and start the containers

```
docker compose up --build
```

> The application will be available at : http://localhost:5173

### 2️⃣ Stop containers
```
docker compose down
```
